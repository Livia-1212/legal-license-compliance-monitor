# Data Dictionary

## Table: attorneys

Stores attorney demographic and employment information.

| Column            | Data Type | Description                              |
| ----------------- | --------- | ---------------------------------------- |
| attorney_id       | Integer   | Unique attorney identifier (Primary Key) |
| name              | String    | Attorney full name                       |
| email             | String    | Attorney email address                   |
| date_of_birth     | Date      | Date of birth                            |
| title             | String    | Professional title                       |
| office            | String    | Office location                          |
| practice_area     | String    | Practice group                           |
| employment_status | String    | Current employment status                |

Primary Key:

* attorney_id

---

## Table: licenses

Stores attorney bar admission and licensing information.

| Column              | Data Type | Description                  |
| ------------------- | --------- | ---------------------------- |
| attorney_id         | Integer   | Attorney identifier          |
| jurisdiction        | String    | Licensing jurisdiction       |
| admission_date      | Date      | Bar admission date           |
| admission_year      | Integer   | Bar admission year           |
| license_status      | String    | Active, Expired, Suspended   |
| registration_expiry | Date      | Registration expiration date |

Foreign Keys:

* attorney_id → attorneys.attorney_id
* jurisdiction → jurisdiction_rules.jurisdiction

Business Rule:

* Attorneys with Expired or Suspended licenses are considered non-compliant.

---

## Table: cle_records

Stores Continuing Legal Education compliance information.

| Column          | Data Type | Description            |
| --------------- | --------- | ---------------------- |
| attorney_id     | Integer   | Attorney identifier    |
| jurisdiction    | String    | CLE jurisdiction       |
| required_hours  | Integer   | Required CLE hours     |
| completed_hours | Integer   | Completed CLE hours    |
| deadline        | Date      | CLE reporting deadline |

Foreign Keys:

* attorney_id → attorneys.attorney_id
* jurisdiction → jurisdiction_rules.jurisdiction

Business Rule:

* completed_hours must be greater than or equal to required_hours.

---

## Table: jurisdiction_rules

Stores jurisdiction-specific compliance requirements.

| Column             | Data Type | Description                 |
| ------------------ | --------- | --------------------------- |
| jurisdiction       | String    | Jurisdiction code           |
| cle_required_hours | Integer   | Required CLE hours          |
| registration_cycle | String    | Annual, Biennial, Triennial |

Primary Key:

* jurisdiction

---

## Table: matters

Stores matter-level information.

| Column | Data Type | Description |
|---|---|---|
| matter_id | String | Unique matter identifier |
| matter_name | String | Name of the legal matter |
| jurisdiction | String | Jurisdiction associated with the matter |
| client | String | Client name |
| revenue | Numeric | Matter revenue exposure |
| matter_type | String | Litigation, Transaction, Regulatory, Commercial, Finance |
| status | String | Matter status |

Primary Key:
- matter_id

Foreign Key:
- jurisdiction → jurisdiction_rules.jurisdiction

Relationships:
- One matter can have many attorney assignments.

---

## Table: matter_assignments

Stores attorney assignments to matters.

| Column          | Data Type | Description                |
| --------------- | --------- | -------------------------- |
| matter_id       | String    | Matter identifier          |
| attorney_id     | Integer   | Assigned attorney          |
| role            | String    | Lead, Supporting, Reviewer |
| assignment_date | Date      | Assignment date            |

Foreign Keys:

* matter_id → matters.matter_id
* attorney_id → attorneys.attorney_id

Relationships:
- Many-to-one relationship with matters.
- Many-to-one relationship with attorneys.

Business Rule:

* Attorneys should not be assigned to matters when their license is expired, suspended, or otherwise non-compliant.
